### 简介

---

Nxtspace Web 是一款面向建筑行业的 3D 场景搭建工具，基于纯 Web 技术构建，无需安装即可在浏览器中使用。

**核心能力：**

- **二维平面图快速绘制**：墙体 / 弧墙 / 门窗 / 区域，配合智能吸附、净距标尺、顶点编辑、尺寸标注、参考线 / 参考图，高效还原户型
- **实时三维可视化**：2D 绘制即时生成 3D 场景，材质 / 轮廓 / 材质与轮廓三种风格渲染 + 画质三档，娃娃屋模式、漫游模式（物理碰撞）、多视角快速切换
- **一键外景**：地图上框选区域，自动生成真实世界的建筑与道路外景，二维三维同步呈现
- **材质体系与素材库**：材质库拖拽铺贴、洪泛铺贴、材质刷吸取涂刷；结构元件 + 分类室内模型，支持自定义模型导入（GLB / ZIP / 批量导入）
- **多人协同**：局域网协同会话，多人同时编辑同一方案，远端光标实时可见
- **多格式导入导出**：NXTS 项目文件、GLTF / GLB / OBJ 三维模型、SVG 二维图纸、PNG 截图，方便对接其他工具链
- **多端适配**：电脑浏览器完整功能体验，手机 / 平板触屏友好操作，支持 PWA 安装到桌面离线使用

无论您是建筑师、室内设计师、地产策划还是产品演示者，都能零门槛上手，快速产出可交互、可分享的 3D 建筑场景 Demo。
